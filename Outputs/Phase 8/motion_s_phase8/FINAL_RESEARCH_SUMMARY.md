# Final research summary

The project progressed from retrieval and English-to-gloss modeling to six-level RVQ motion-token generation, strict decoder recovery, and empirical normalization recovery. Phase 5 exposed severe duration, collapse, and repetition failures. Phase 6 reduced oracle duration MAE from 590.874 to 1.491 frames through explicit length control, while showing token quality remained poor. Phase 7 SC-POINT improved micro token accuracy to 0.147933, edit distance to 0.838971, and collapse to 0.474658. Phase 8 selected **dynamics** by validation only (lambda_velocity=0.1, lambda_persistence=0.0). Final oracle micro accuracy is 0.150157; normalized feature MAE is 0.842483; collapse is 0.505229. Final deployable duration MAE is 79.077 frames. These are token/feature-space results, not proof of linguistic sign correctness.
